## 制作与证据状态

当前会话没有presentations工具，用户已明确接受使用现有工具生成PPTX。本版本使用python-pptx制作。简洁商务风格采用深蓝、青绿与白灰配色；每页3—4条要点，右侧配对应机制/流程示意图。所有机制图均为原创概念示意，未伪装成计算结果或真实晶体结构。

PDF由与PPT相同的版式数据生成，为阅读预览；实际PowerPoint显示可能因字体替换略有差异。主字体为Microsoft YaHei，科学字符采用Cambria回退；本地预览采用Noto CJK与DejaVu字体。

生成源码为[生成源码.py](生成源码.py)，内容数据为[汇报内容.json](汇报内容.json)。重建需要Python及python-pptx、Pillow、fonttools，并可读取源码所列字体路径。运行：`python 生成源码.py`。
