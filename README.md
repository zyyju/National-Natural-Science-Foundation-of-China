## 当前状态

材料为修订工作稿。研究对象限定为SmMg₂Bi₂与Ca/Ge双位点取代，以局域畸变和载流子散射为主线，AI用于小样本主动选点与信息整合，热输运为辅助检验。

提交前须核实省基金ZR2024QA209的任务边界、母相初算及显式散射样例、相关原始实验文献和软件/机时条件；申报栏目与研究期限以2027年度正式要求为准。正文中的【待核实】应据真实证据补齐。采样规模、候选数量和验收标准为拟议设计，未完成计算不作为已有结果。
